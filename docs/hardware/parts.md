# Parts list

This is the full list of parts read from Naya's public FCC filings for the Create halves, the
Speedlink dongle and the Tune, Touch and Track modules, with the unconfirmed readings kept apart
from confirmed part numbers, and the open hardware questions with what would settle each. The same list is published as a data file,
[`parts.json`](../assets/data/parts.json). The one thing to know: every photographed unit is a
pre-production sample the lab received on 2025-06-20, so retail boards may differ.

!!! note "At a glance"
    - 222 main rows: 199 confirmed and 16 corrected by a blind re-read, plus 7 new rows from the exhibits obtained on 2026-09-23 (one extraction pass).
    - 21 identified part numbers, 20 boards, 47 unconfirmed readings, 26 open questions.
    - Nothing was opened for this list: it reads only public FCC exhibits, vendor manuals and datasheets.
    - Candidates in the unconfirmed table are reasoning, never part numbers.
    - Data file and page are CC BY 4.0; the facts come from public records.

## What the list is and how it was verified

<!-- parts facts 1-2, 5, 15-16 -->
The list was built from the FCC exhibits in 25 extraction passes and then checked by 16 adversarial
passes that re-read every cited crop blind and gave each row a verdict; the method is described on
[Board inventory](index.md#how-the-parts-were-read) <span class="tag doc">DOC</span>. When it was built it had 215 main rows (199
confirmed, 16 corrected), 21 identified part numbers, 48 unconfirmed readings, 50 rejected readings
and 27 open questions across 20 board entries. The 16 exhibits obtained on 2026-09-23 add 7 rows
(LB-20 left label, LB-21 dongle label, LB-22 confidentiality letters, LB-23 dongle SAR report, LB-24
left-half RF-exposure report, DG-19 dongle antenna position, ACC-08 SAR extension cable), settle one
unconfirmed reading (U-LB-04b, the ISED numbers) and one open question (OQ-25, the missing exhibits),
and extend about 20 rows: 222 main rows, 47 unconfirmed readings, 50 rejected readings and 26 open
questions now. The 7 new rows had one extraction pass, not the blind re-read <span class="tag doc">DOC</span>[^fcc].

Verdicts: **confirmed** (a blind re-read found the same marking and the identity holds),
**corrected** (the re-read found a different or fuller value, which the row now carries),
**unverifiable** (kept only in the unconfirmed table), **refuted** (dropped from the list), and
**new** for the 2026-09-23 rows <span class="tag doc">DOC</span>. The list reads only public FCC exhibits and vendor manuals
and datasheets; no hardware was opened for it <span class="tag doc">DOC</span>. The page and the data file are licensed CC BY 4.0
like the rest of the site; the underlying facts come from public FCC records[^license].

## How to read a row

<!-- parts facts 3-4, 6, 9 -->
Each row carries an ID, the location on the board, the part, the maker, the function, the marking as
read (verbatim, followed by a legibility mark [clear], [partial] or [illegible]), the source (FCC ID,
exhibit and lab attachment page, as explained on
[Regulatory records](regulatory.md#how-to-cite-an-fcc-photo)), the basis (tag and verdict) and notes
<span class="tag doc">DOC</span>. The sections are: identifiers and marks; board inventory; half mainboard; wing; dock (thumb-key)
board; module dock interface; half enclosure, switches, keycaps and mechanics; dongle; Tune main
board; Tune disc, dial and enclosure; Touch main board; Touch sensor, pogo and enclosure; Track main
board; Track sensors, pogo, interposer, motor and enclosure; batteries and ratings; accessories in
the box <span class="tag doc">DOC</span>.

A "candidate" in the unconfirmed table is reasoning and never a part number: for example a Winbond
W25Q family and capacity for the flash, a C&K PCM12-class slide switch, `NAYA-700-3` for the Tune
base, WS2812/SK6812 for the LEDs, CST3640 for the Tune disc <span class="tag doc">DOC</span> <span class="tag inferred">INFERRED</span>. Rows measured on hardware read
`measured on one <unit>, <firmware>, <date>`. The list contains no serial number, serial-number
template value, lab sample number or QR payload: where a label has a serial field, the row says that
the field exists and gives no value <span class="tag doc">DOC</span>.

  dongle's placeholders (LB-05, LB-06), the marks on the left and dongle labels (LB-07 to LB-13), the

  RF window) from INFERRED to DOC on the vendor's own statement <span class="tag measured">MEASURED</span> <span class="tag doc">DOC</span>[^ks-14][^ks-15].

Already answered since the list was built: the half's dock magnets are real magnets, 6 per bay, the 2

bay bracket (PD-09) did not attract a steel paper clip <span class="tag measured">MEASURED</span> (owner's board, 2026-09-23) <span class="tag inferred">INFERRED</span>. OQ-13 stays
open for the module bases.

## About the images

The photos on this page and the other hardware pages are crops of Naya B.V.'s FCC exhibits, which
are public records on [apps.fcc.gov](https://apps.fcc.gov/oetcf/eas/reports/GenericSearch.cfm)
(grantee code 2BQ4V). Identifying marks were removed before publication: QR and 2D codes, serial
numbers and serial-number fields, lab sample tags and handwriting are blurred or blacked out, while
part markings and board silkscreen are left legible. Each image cites its FCC ID and exhibit: board
views in their caption, part crops in the title shown when the image is opened. A row without a crop
of its own shows its board instead, and a dash means there is nothing to photograph (report text,
USB descriptors, manual text). Click any image to zoom <span class="tag doc">DOC</span>[^fcc].
